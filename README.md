Tranzzy – Tour & Courier Management Desktop Application

Overview:
Tranzzy is a desktop-based Java application built with Swing for an interactive graphical user interface and MySQL (via JDBC) for data storage and management. It offers a seamless experience for users to book tours or send couriers, with automated fare calculations based on selected facilities and preferences.

Key Features:

User Accounts:
Users can register, log in, and manage their profiles while viewing their booking and courier history.

Tour Booking System:
Choose your destination, pickup location, transport type, number of seats, and vehicle type (AC/Non-AC).
The system dynamically calculates the total fare based on user selections.

Courier Service:
Send parcels by specifying sender and receiver details, pickup and delivery locations, weight, and delivery preferences such as:

Fragile item

Urgent delivery

Cash on Delivery (COD)
The courier fare is automatically calculated according to the selected options.

Admin Panel:
A single admin can view, edit, or delete all tour and parcel records, maintaining full control over the system’s data.

Database Integration:
All data is securely stored in a MySQL database using JDBC connection, ensuring persistence and reliability.

Modern Swing UI:
The application features an intuitive and visually appealing interface created with Java’s Swing library for a smooth user experience.

Tech Stack:

Language: Java

GUI Framework: Swing

Database: MySQL

Database Connectivity: JDBC

Purpose:
Tranzzy is designed to provide users with a convenient and efficient way to manage tours and courier deliveries from one unified platform, while offering admins complete oversight of system operations.
